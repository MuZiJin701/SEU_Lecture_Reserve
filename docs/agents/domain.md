# 领域文档

采用 single-context：东南大学素质讲座预约。

- 探索代码前，读[词汇表](../../GLOSSARY.md)及 `docs/adr/` 中与任务相关的决策；不存在时继续，不建占位文件。
- Issue、设计和测试使用词汇表名称；新概念确定后按 `domain-modeling` 格式记录。词汇表只解释领域含义，命令和实现留在使用指南或代码。
- 真实架构权衡需要保留时才建 ADR；方案与已有 ADR 冲突时，先指出决策及重议理由。
- 操作见 [README](../../README.md) / [English](../../README.en.md)，约束见[浏览器规格](../browser-upgrade-requirements.md)；行为仍须核对代码。
