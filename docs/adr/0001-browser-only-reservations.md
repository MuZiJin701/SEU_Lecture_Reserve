# 全程由 Playwright 操作浏览器，保持两个项目独立

2026-10-18 决定：保留独立 HTTPS 项目，本项目由 Playwright 操作页面完成登录、查询、验证码、提交和核对，保留可见的操作过程。所有平台默认显示窗口，用户用 `--headless` 自选无头。

复用 HTTPS 项目的目标、状态和邮件逻辑，两仓库无运行时依赖。页面未完整展示 ID 和状态，因此只读 Vue 绑定数据并按 ID 定位卡片，业务仍通过控件操作，不调用 Vue 业务方法或另建请求客户端。代价是依赖页面与 Vue 结构；改版或记录不完整时暂停新增，不能按标题猜测身份或默认无冲突。

认证受阻时保留任务、停止业务并按邮件配置通知；不提供短信交互或远程桌面，无头与邮件不能保证长期无人值守。

每次普通启动都以网站记录重建进度，包括本地曾完成时。本地检查点仅辅助本机恢复，新机器无需迁移状态，不提供跨机器接续。约束和验证边界见[浏览器规格](../browser-upgrade-requirements.md)。
